# Chart.js Doughnut Chart with Hover Text

A doughnut chart built with Chart.js 3.7.0 in plain HTML, CSS and JavaScript. A custom plugin draws the label and value of the hovered segment in the center of the chart.

## Getting started

Open `index.html` in your browser. No build step or installation is needed, Chart.js is loaded from a CDN.

## Project structure

```
.
├── index.html
├── style.css
└── script.js
```

`script.js` is split into four blocks: data, the hoverLabels plugin, config and render.
